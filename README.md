# java-racingcar-precourse
## 📍구현할 기능 목록
**1. 입력**
- 자동차 이름과 시도 횟수를 입력 받는다
  - 빈 값, 시도 횟수 검증
- `,`을 기준으로 자동차 이름을 분리한다
  - 자동차 이름 길이 검증

**2. 자동차**
- 입력받은 이름을 저장한다
- 총 움직임을 저장한다

**3. 난수 생성**
- 0에서 9사이의 난수를 생성한다

**4. 경주**
- 입력받은 횟수만큼 라운드를 진행한다

**5. 출력**
- 최종 우승자를 출력한다
